# Secure Banking Application

## Description
A console-based banking application written in Java. It demonstrates Object-Oriented Programming
and secure coding practices, with all data persisted to plain text files (no database).

## Features
- User registration and login
- Create bank accounts (multiple per user) and view balances
- Deposit and withdraw funds
- Transaction history per account
- Persistence to `data/users.txt`, `data/accounts.txt`, `data/transactions.txt`, loaded at start-up
